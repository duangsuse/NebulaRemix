# Feetless

为需要调用本机API的H5应用（如离线PWA）， `{$}=Feetless(8086+ PORT)` 是一个类bash JSON-RPC 框架，能够有效阻止字符串注入、代码投毒、跨版本错误。它兼容stdio和(以POJO传参和返回的) pyjs, pwsh, jsh (C# Java) 等语言，绿色免安装，就像NSIS一样精巧。

比如调用： `await $'echo ${1}'.alike(/^/)` 总是返回str("1")或以 `.onerr(i=>i!=0 ..)` 报错， `await p$'ls|select name'.alike([{Name:""}])` 即生成相应的 .ts 结构乃至递归检查器。 


**新加调用后，需逐个执行到，然后在项目根执行** ` Get-Clipboard|patch `。 修改调用后，只需在结尾换行，重复增加动作后恢复。

```js
let {call, $, p$, py} = Feetless(8086+ PORT)

echo=call(async(u)=>{
  let a=await p$`echo dear ${{u}}`.alike([""])

  return [await $`echo ${{str:"Hello \""}}`, ...a]
  // 因包含 let a; 必须使用call以保证栈内存回收
})

echo('Rose').then(u=> dd=u) //dbg display
```

Web3 是一种全球唯一的网站，它让用户账号可以“拥有”跨越应用的数据、媒体文件，比如存款凭据、音乐专辑、游戏装备，它们无需许可或编程即可自由买卖租用

如果说，微信支付和淘宝是让银行金融从纸面上、卡号上，移动到手心里，Web3 就是距离与信任感的终极解决方案：能通话，就是能发钱！

Web3 的最大贡献是“零知识证明”。通过让转账消息在算法和经济性上无法伪造或撤回，Web3 上的网络信息拥有和群聊私聊一样，自动扩散的所有权。它不依赖于链下支付，不以公司集团为界限，漫延于整个线上世界。

因为 Web3 上的项目可接入发行协议、跨链桥、预言机，从而融化应用程序、链与链、网与网之间的“冻结壁垒”。 常见的公链有 EVM系(BSC, BASE, ERC, TRCv2.0) / SOL / TON，都是通过“网费币”的质押与小费来运营，却不可以耗电“挖矿印钞”！

相较于 https、IPFS、Tor 等加密平台，Web3 更注重能制造共识的产品和技术，因为 共识>信任，共识使建立信任的效率与时间解绑。Web1 可查找，Web2 可分享，Web3 数据库的可铸造，却是源于对“价值互联”的认识。

如果你身边51%的人都不会去街上撒钱，并且向这种亲戚抗议，你就应该相信钱包里的那12个词和它拥有的稳定币，因为这就是区块链与交易所的工作原理。 但是如果51%的人都那么做了？那或许就是储蓄因AI普及而购买力爆表的那天吧！

>区块链：大家一起记账，改旧账就要说服后面所有人重写。
想象一个楼栋的地址-交易表，每页写满后就盖章封存，下一页链在上一页后面。想偷偷改第2页的内容或余额？你得把第2页到最新一页全部重写，还要让所有人同意你的新版本。这太费劲了，所以旧账几乎改不了——从1层楼到一个星球都一样！

区块链没有魔法。 代币、通肯(Token)、CA(合约地址) 都代表一种余额，由Web3数据库上显示的网站(“DApp”或合约代码) 做财务加减。 这些合约通过ERC、SPL等接口来为币种设计视觉特征。

BTC/ETH/SOL 的账户余额模型有着不同的隔离性(UXTO/CA/ATA)，但知道币种、私钥和对方地址就能无限制转钱。自由和用户主权也意味着用户责任，不要出售“零余额钱包”的12词种子。
